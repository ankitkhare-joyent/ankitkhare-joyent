# Ankit Khare

I'm a data platform technical lead at Joyent (Samsung Cloud). I build data and AI
infrastructure on Kubernetes: a managed Spark service compatible with AWS EMR on EKS,
the Apache Iceberg lakehouse that runs on it, and a Text2SQL API that answers
infrastructure questions in Slack.

My work code lives in private company repositories. The projects below are hands-on
labs I built to go deep on the tools I use at work and the ones coming next. Each one
runs locally with Docker and has its own write-up.

| Project | What it covers |
|---|---|
| [semantic-txt-2-sql](https://github.com/ankitkhare-joyent/semantic-txt-2-sql) | Text-to-SQL agents over an Iceberg lakehouse, built three ways (Cube semantic layer, raw SQL, hybrid) and measured against each other |
| [learn-ai-agent](https://github.com/ankitkhare-joyent/learn-ai-agent) | An MCP server and Claude agents over an EC2 inventory lakehouse: Iceberg, a REST API, the MCP layer |
| [agent-evals-observ](https://github.com/ankitkhare-joyent/agent-evals-observ) | Agent evals and observability: OpenTelemetry GenAI tracing, Langfuse, offline and online evals |
| [rag-vector-srch](https://github.com/ankitkhare-joyent/rag-vector-srch) | RAG and vector search: pgvector hybrid search, reranking, evals, citations |
| [flink-learning](https://github.com/ankitkhare-joyent/flink-learning) | Stream processing: Kafka, Flink SQL, Debezium and Iceberg around a real-time EC2 inventory |
| [llm-from-scratch](https://github.com/ankitkhare-joyent/llm-from-scratch) | A small modern decoder-only LLM, built and trained from scratch on a laptop |
